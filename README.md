# MemoryLink

A Java Spring Boot learning website based on the provided wireframe.

## Features
- Landing page
- Login page
- Strand selection
- Subject selection
- Lesson selection
- Lesson information
- Flashcards
- Quiz

## Requirements
- JDK 17 or newer
- Maven

## Run in VS Code

Open the project folder, then open Terminal and run:

```bash
mvn spring-boot:run
```

Then open:

http://localhost:8080

## Website Flow

Landing Page
→ Login
→ Select Strand
→ Select Subject
→ Select Lesson
→ Lesson Information
→ Flashcards or Quiz

Note: This is the first functional frontend version. Admin upload, database, real authentication, and progress tracking can be added next.
